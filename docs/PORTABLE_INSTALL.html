다른 Windows PC에서 시작하기

기존 PC에 접속하는 방식이 아닙니다. 이 폴더를 새 PC에 복사하여 그 PC에서 독립적으로 실행합니다. Codex 설치는 필요하지 않습니다.

1. 압축 풀기

ZIP을 새 PC의 C:\SupplierHub 같은 작업 폴더에 모두 풀어 주세요. ZIP 안에서 바로 실행하지 마세요. migration, scripts, dist, public 폴더를 함께 둡니다.

2. 처음 한 번 설치하기

필요 항목용도
Node.js 24 이상로컬 서버 실행 및 프로그램 의존성 설치
Python 3.10 이상엑셀 작성·PDF 처리. 처음 설정이 전용 .venv와 필요한 라이브러리를 만듭니다.
Google ChromeSupplier Hub와 로젠 웹사이트 연결
데스크톱 Microsoft Excel발주서 XLSX 인쇄. 웹용 Excel만으로는 지원하지 않습니다.
PowerShell 7로젠 송장 출력 보조 프로그램
프린터 드라이버발주서, 로젠 송장, 입고 라벨·내역서 프린터를 Windows에 설치

처음설정.cmd를 더블클릭하세요. 처음 설정에는 인터넷 연결이 필요합니다. 화면에 나오는 프린터 번호를 각각 선택합니다. 기존 업무 기록은 새 폴더로 가져오고 파일 경로를 연결합니다. 이미 업무 DB가 있는 폴더에는 덮어쓰지 않습니다.

발주서 프린터를 Windows 기본 프린터로 지정하세요. 사용자 이름이나 프린터 이름이 바뀌면 처음 설정을 다시 실행할 수 있습니다. 전체 폴더를 다시 이동하면 Python 환경과 파일 경로가 달라지므로 새 패키지로 이전하는 편이 안전합니다.

3. 환경 확인 후 업무 시작

실행환경확인.cmd를 실행하고 ‘설정 필요’ 항목을 해결하세요. 이후 업무시작.cmd를 더블클릭합니다. 로젠 출력 보조 프로그램의 Windows 권한 확인 창이 나타나면 내용을 확인하고 승인하세요.

초보자용: http://127.0.0.1:4310/fulfillment/beginner
전문가용: http://127.0.0.1:4310/fulfillment/expert

새 PC에서 Supplier Hub와 로젠에 다시 로그인합니다. 이 패키지는 이전 PC의 로그인 쿠키·비밀번호·API 비밀키·출력 보조 토큰을 옮기지 않습니다. 공식 API 방식을 사용한다면 .env에 새 PC에서 사용할 API 설정을 직접 넣어야 합니다.

4. 업무 기록과 파일 확인

  1. 현재·이전 발주와 등록·송장 이력이 보이는지 확인합니다.
  2. 발주서 열기로 실제 파일이 열리는지 확인합니다.
  3. 카톤 수량 미리보기에서 상품·수량·수취 정보를 확인합니다.
  4. 프린터 및 웹 화면 연결을 확인한 뒤 새 PC를 운영 PC로 사용합니다.

이전 자료는 패키지를 만든 시점의 사본입니다. 기존 PC에서 이후 업무를 했다면 최종 이전 직전에 업무를 마치고 이전용패키지만들기.cmd로 다시 내보내세요. 전환 후에는 한 PC에서만 실제 주문 등록·출력을 진행하세요.

원래 PC에서도 없었던 파일은 자동으로 복원되지 않습니다. migration/manifest.json의 missingFiles와 data/portable-import.json을 확인하세요. 카톤 확인 자료의 경로가 바뀌면 다시 자동 대조하며, 불명확한 값은 예외로 남습니다.

끝내기·문제 확인

진행 중인 업무가 끝나면 업무종료.cmd로 이 폴더의 서버를 종료합니다. 관리자 권한 보조 프로그램을 종료하지 못했다면 업무종료를 관리자 권한으로 실행하세요. 다른 폴더의 서버를 임의로 종료하지 않습니다.

화면이 열리지 않으면 data/server.stderr.log, 송장 보조 프로그램이 준비되지 않으면 data/logen-windows-mcp.stderr.log를 확인하세요. 화면이 정상이라는 사실만으로 실제 등록이나 프린터 출력이 완료된 것은 아닙니다.
