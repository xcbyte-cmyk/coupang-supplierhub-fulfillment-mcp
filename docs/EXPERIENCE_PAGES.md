# 초보자용·전문가용 화면

2026-09-15 구현. 두 화면은 동일한 실행 로직과 저장 데이터를 사용한다.

| 주소 | 대상 및 구성 |
| --- | --- |
| `/fulfillment`, `/fulfillment/beginner` | 초보자용. 재고 확인, 네 묶음의 진행 상태, 지금 할 일과 실행 버튼, 예외 수량 보완, 발송 일정, 간단한 작업 선택, 이동식 작업 도구와 화면 초기화 |
| `/fulfillment/expert` | 전문가용. 전체 설정, 16개 단계별 실행, 묶음 실행, 자동 수량 확인, 실행 원문, 복구·이력 및 이동식 작업 도구 |

초보자용은 기본 진입 화면이다. 위의 화면 전환 링크는 선택한 Run·Scan과 조회 기간, 대상 발주, 연동 방식, 발송 일정 값을 URL 매개변수로 넘긴다. 저장하지 않은 품목별 수량·근거 편집은 별도 저장 데이터가 아니므로 화면 전환 전에 마친다. 실행 또는 녹화 중에는 전환을 막는다.

## 초보자 안내 규칙

1. 첫 번째 영역에서 실제 상품별 재고를 확인한다. 체크는 같은 탭·날짜·선택 작업 동안 유지하는 작업 안내이며, 재고 시스템의 조회나 재고 원장을 변경하지 않는다.
2. 선택 작업의 저장된 완료 이력에 따라 발주 준비, 발주 확정·인쇄, 배송·송장, 입고 마무리 중 이어할 작업을 안내한다.
3. 카톤 수량에 예외가 있으면 수량 보완으로 이동한다. 정상 품목의 자동 확인 규칙은 두 화면에서 동일하다.
4. 송장번호 선택이 필요한 경우 번호 확인 화면을 연다. 발주확정·배송등록·입고등록 결과가 불명확하거나 부분 완료이면 전문가용의 결과 확인으로 안내한다.
5. 실행은 기존 `runStageRange`, 등록 미리보기, 발주확정 검토, 송장번호 확인을 재사용한다. 화면 전환이나 현재 상태 조회만으로 업무를 실행하지 않는다.

## 초보자용 작업 도구와 초기화

- 초보자용에도 녹화, 현재 실행 확인, 현재 작업 실행, 전체 실행, 모니터링, 다음 단계 전 멈춤을 제공한다. 기존 실행·검토 경로를 재사용하며 전체 실행 전에는 재고 체크가 필요하다.
- 넓은 화면에서는 오른쪽 도구 공간을 확보하고, 작은 화면에서는 접힌 도구로 시작한다. 도구는 드래그·접기·펼치기가 가능하며 초보자용 위치·모니터링 설정은 전문가용과 별도로 유지한다.
- `화면 초기화 · 새로 시작` 또는 도구의 `화면 초기화`는 Run·Scan 선택, 조회 및 발송 입력, 수량 초안·확인 체크, 화면 진행 표시를 비운다. 저장된 발주·상품 기준·등록·인쇄·단계 이력은 삭제하지 않는다. 초기화 함수는 서버 초기화·삭제 API를 호출하지 않는다.
- 초기화 후 URL에 `fresh=1`을 반영해 새로고침이나 화면 전환 후에도 최근 작업을 자동 재선택하지 않는다. `다른 작업 이어하기`에서 기존 작업을 선택하면 다시 이어가고 새 시작 표시를 해제한다.
- 업무 실행, 녹화 또는 검토 창이 열린 동안 화면 초기화를 비활성화한다. 단계·등록 이력 초기화는 전문가용에서 수행한다.
